Common Troubleshooting

Windows / Microsoft Store Installation

Ensure your system has 64-bit Windows 10/11. AutoFlow requires SSH client capabilities (enabled by default on modern Windows). If you encounter permission prompts, grant the local network permission for local SSH tunneling.

Does AutoFlow send my private keys to the cloud?

No. AutoFlow is 100% local-first. Your private keys never leave your device. All SSH connections and file synchronizations occur directly between your computer and your target VPS.
